Get started

Install CASTmir

Not in the Chrome Web Store yet — during the pilot it installs directly from this file. Works in Chrome, Edge, Brave and other Chromium browsers. Takes about two minutes.

  1. Unzip the file. Right-click the downloaded zip → Extract All (Windows) or double-click it (Mac). Keep the resulting castmir-extension folder where it is.
  2. Open your browser's extensions page. Chrome: chrome://extensions · Edge: edge://extensions · Brave: brave://extensions
  3. Turn on Developer mode. Toggle it on — usually top-right of the page. Three new buttons appear.
  4. Click "Load unpacked". Select the castmir-extension folder (the folder itself, not a file inside it).
  5. Pin it to your toolbar. Click the puzzle-piece icon in your toolbar, find CASTmir, click the pin.
  6. Check the server URL. Click the CASTmir icon → Settings. It should already point at . Set your department here too.
  7. Visit a supported AI site and approve it. Go to ChatGPT, Claude, Gemini, Copilot or Perplexity. CASTmir shows a consent card — approve the site. From then on, every prompt you send is scored before it leaves your browser.

Your browser may warn that the extension isn't from the Web Store — expected during the pilot, safe to proceed.

Prompt Coach

Scores clarity, context, specificity, structure and output instructions, then offers a revision you can apply with one click.

Security Agent

Detects PII, credentials, confidential content and prompt injection, and observes, warns, redacts or blocks according to policy.

Model Tracker
